# Dima404 — личный сайт

Статический сайт без сборки: чистые HTML/CSS/JS + один `data.json`.
Открывается локально и разворачивается на любой VPS как обычные файлы.

## Структура

```
dima404-site/
  index.html            # главная страница
  404.html              # страница ошибки
  assets/
    css/style.css       # база + 6 тем (CSS-переменные)
    js/app.js           # рендер разделов, переключение тем, поиск
    data/data.json      # ВЕСЬ контент: лор, музыка, игры, кино, железо, соцсети
    img/avatar.png      # аватар
  tools/parse_chat.py   # разбор экспорта Telegram в текстовый дамп
  deploy.ps1            # заливка на VPS по ssh/scp
  out/                  # черновые дампы (в деплой не входит)
```

## Как править контент

Всё в `assets/data/data.json`:

- `profile` — имя, ник, город, подпись
- `timeline` — лор по годам
- `music` — треки (`t` название, `a` исполнитель, `d` длительность, `g` жанр из `genres`)
- `steam` — два аккаунта: `accounts[].games` (топ-10 по часам, `appid` нужен для обложки)
- `watch` — просмотренное (`k`: `anime` / `series` / `movie`, `d` дата, `e` эпизод, `tr` перевод)
- `now` — чипы «сейчас» на главной
- `hobbies`, `lab`, `devices`, `socials`, `facts`

## Локальный запуск

Из-за `fetch()` нужен http-сервер, просто двойным кликом данные не подтянутся:

```powershell
cd F:\Dima\Documents\Ai\dima404-site
python -m http.server 8080
# открыть http://localhost:8080
```

## Деплой

```powershell
.\deploy.ps1 -Vps 85.209.3.56 -Key "$env:USERPROFILE\.ssh\vps_ai"
```

Сервер: Debian 12, nginx 1.22, файлы в `/var/www/dima404` (160 КБ).

**Сайт намеренно закрыт снаружи**, пока нет домена:

- nginx слушает только `127.0.0.1:80`
- в `ufw` правило `80/tcp` удалено
- `xray-standalone` и `x-ui` работают как раньше, порты VPN не тронуты

Посмотреть локально через SSH-туннель:

```powershell
ssh -i "$env:USERPROFILE\.ssh\vps_ai" -L 8080:127.0.0.1:80 root@85.209.3.56
# затем открыть http://localhost:8080
```

Открыть наружу (когда будет домен): в конфиге вернуть `listen 80;`, в `ufw` — `ufw allow 80/tcp`.

## Домен и HTTPS

443 занят Xray (VLESS Reality), поэтому классическая схема «nginx на 443 + certbot» не подойдёт.
Варианты:

1. **Cloudflare Tunnel** — бесплатно, без открытых портов, HTTPS на стороне Cloudflare, IP сервера скрыт. Нужен домен (подойдёт и бесплатный поддомен).
2. **Let's Encrypt через DNS-01** — сертификат выпускается без порта 80/443, нужен DNS-API (DuckDNS/Cloudflare). Дальше nginx слушает свободный порт (например, 8443 нельзя — занят, значит 9443).
3. **Освободить 443** — перенести Xray на другой порт (не рекомендую, сломает клиентов).

Бесплатные домены: `*.duckdns.org`, `*.is-a.dev`, `*.pp.ua`, `*.eu.org`.
Дешёвые настоящие: `.xyz` / `.top` / `.icu` — 1–3 $ в год.

## Размер

Весь сайт (без аватара) — ~100 КБ. Аватар — WebP 512×512, 42 КБ.
Обложки игр тянутся с CDN Steam, постеры не хранятся вовсе.

## Данные Steam

Библиотеки выгружены через `IPlayerService/GetOwnedGames` (ключи лежат только в `out/steam_*.json`, в сайт не попадают).
Обновить часы: положить свежие ответы API в `out/steam_main.json` / `out/steam_old.json` и запустить:

```powershell
python tools\enrich.py
```

## Приватность

Ключи Steam API и экспорты чатов (`out/`) в деплой не входят — `deploy.ps1` копирует только `index.html`, `404.html` и `assets/`.
